# 更新日志

## 1.1.2 临时修复（2026-11-17）

- 血量读取或原生 UI 更新发生运行时异常时，清除旧样本和文字状态；下一次查询到固定运行期实体 ID `0x1000000F` 时重新采样，保留约 100 ms 的采样限频。
- 血量样本超过 750 ms 未更新时重置显示；原 UI 回调线程超过 750 ms 未成功更新时，允许新的有效回调线程接管。释放重置时克隆的旧文字，避免累积隐藏对象。
- 血量显示功能本身已在国服 7.2 幽境危战第一间的单血条 Boss 场景测试；本次**由实体查询触发恢复的逻辑尚未测试**。适用范围见[血量显示说明](README_STYGIAN_HP.md)。

## 1.1.2

- 在“体验优化”加入默认关闭的“幽境 Boss 当前血量”，在已验证的国服 7.2 单条 Boss 血条右侧显示本地当前 HP。
- 加入默认开启的“同时显示最大血量”；开启时显示 `当前 HP / 最大 HP`，关闭时只显示当前 HP。两个选项支持运行时热重载。
- 保留 1.1.1 的秘境地图、技能 CD 和主/备选 FPS 挡位功能。
- 固定实体 ID、血条形状与游戏构建校验限制见[血量显示说明](README_STYGIAN_HP.md)。

## 1.1.1

- 加入[秘境内奖励来源跳转地图](README_DOMAIN_MAP.md)，默认关闭，只在指定国服 7.2 游戏程序的 SHA-256 和函数入口匹配时安装 Hook；该构建已完成游戏内验证。
- 集成独立的 [DisplayCD 1.0.3](README_SKILL_CD.md) 插件，在队伍栏显示 E、Q 冷却和战技充能次数，默认关闭；本机国服 7.2 构建已完成游戏内验证。
- 加入[主/备选 FPS 挡位与切换快捷键](README_FPS_TOGGLE.md)。`TargetFps` 保存当前目标值，切换时保留两个预设挡位；快捷键只在游戏窗口前台生效。
- 自包含版不依赖目标机安装 .NET；轻量版需要 .NET 8 Windows Desktop Runtime x64。两版均内嵌三个原生 DLL 与技能 CD 默认配置。

## 1.1.0

- 对照 FufuLauncher.UnlockerIsland `2de496a` 的 7.2 源码更新固定入口。国服与国际服 `SetActive` RVA 分别为 `0x1463FC0`、`0x1464FC0`；国际服 `EventCamera` RVA 为 `0xC5438F0`。使用前校验可执行区域及函数入口。
- 队伍过渡动画改为 7.2 的 `MoveNext` 协程 Hook，保留原生页面就绪判断，只在页面就绪时临时缩短动画。
- 同步 FPS、FOV、VSync、合成、雾效、角色淡出及烹饪的 7.2 特征码。随身烹饪的调用路径保持原有逻辑。
- Visual Studio 2022 Release x64 解决方案及两种 GUI 发布包构建通过。

## 1.0.1

- 修复游戏 7.0 更新后“隐藏 UID 水印”不生效的问题，分别适配国服与国际服的新版 `SetActive` 地址。
- 增加地址有效性与函数头校验；版本失配时只停用隐藏 UID，降低错误地址调用风险。
- 其余 FPS、FOV、队伍动画、大招镜头、雾效、角色淡出、随身合成和随身烹饪功能沿用 1.0.0。
