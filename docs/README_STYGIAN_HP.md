# 幽境危战 Boss 血量显示

在启动器“体验优化”中勾选“幽境 Boss 当前血量”，即可在已验证的单条 Boss 血条右侧显示本地读取的当前 HP。勾选“同时显示最大血量”时格式为 `33,515,578 / 33,517,378`；取消后仅显示当前 HP。总开关默认关闭，最大血量选项默认开启。游戏运行期间修改这两个选项会写入 `Plugins/config.ini` 并热重载。

## 已验证范围

- 国服 7.2 `YuanShen.exe`，SHA-256：`8B014F64B5DC12FBC476E0C362B053ABFDD7A1378CD282E4AD81057621DBD6B5`。
- 幽境危战第一间、单条 Boss 血条，1920×1080 全屏。血量显示功能本身已在该环境完成游戏内测试，字号 24、当前/最大 HP 格式和位置符合预期；本次**由实体查询触发恢复的逻辑尚未测试**。
- 读取已验证的运行期实体 ID `0x1000000F`：属性 `1010` 为当前 HP、`2000` 为最大 HP。约 100 ms 轮询，仅在格式化后的数字变化时改写文字。千万级 HP 由游戏本地 `float` 提供，个位数可能有舍入。

插件在安装可选 Hook 前核对游戏 PE 时间戳、映像大小、校验和及所调用原生方法的入口字节。不匹配时该功能停用，不影响其他体验选项。它从现有 Boss 血条克隆 `UnityEngine.UI.Text`，文字随血条位置移动；血条失效或数据过期时隐藏。

## 运行中恢复

运行时属性读取或原生 UI 调用发生异常时，功能会暂时隐藏文字并清除旧样本。下一次查询到固定实体 ID `0x1000000F` 时会重新采样；采样本身仍有约 100 ms 的限频。血条更新时若发现样本已超过 750 ms，会清除缓存并释放旧文字，下一次有效样本重新初始化显示。原 UI 回调线程超过 750 ms 没有成功更新后，新的有效回调线程可以接管。游戏构建或原生方法校验失败仍会停用该功能。

## 范围限制

当前实现只读取上述固定运行期 ID，没有建立任意血条与对应怪物实体的绑定；多血条 Boss、其他房间和其他游戏版本均不保证数字准确，也未做兼容性验证。代码没有严格识别幽境场景，开关打开后依靠固定实体 ID 与血条形状筛选，因此请只在已验证的单血条场景使用。

实现位于 `Plugin/StygianHpDisplay.cpp`，使用 LiteUnlocker 现有的配置热重载和 MinHook 初始化流程；血量显示不会修改怪物 HP。
